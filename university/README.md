# University labs

Freshman-year lab work from INHA University. The sources identify the author as Alimov Abdullokh

## Lab Assignments 1

Introductory C++. Each program is `main.cpp`.

| Week | Description | Concepts |
| --- | --- | --- |
| [week-02-geometry](lab-assignments-1/week-02-geometry) | Circle, triangle, and related numeric exercises | Variables, formulas, conditions |
| [week-03-conditions](lab-assignments-1/week-03-conditions) | Temperature conversion, number checks, and a year check | `if` / `else`, input |
| [week-04-loops](lab-assignments-1/week-04-loops) | Range sum, Fibonacci, digit sum, primes, and a series | `while`, `for` |
| [week-05-operators](lab-assignments-1/week-05-operators) | Sums and arithmetic-operator exercises | Loops, operators |
| [week-06-patterns](lab-assignments-1/week-06-patterns) | Patterns printed with nested loops | Nested loops |
| [week-09-functions](lab-assignments-1/week-09-functions) | Circle area, swapping two values, and converting time | Functions |
| [week-10-templates](lab-assignments-1/week-10-templates) | Areas of shapes, including a function template | Functions, templates |
| [week-11-recursion](lab-assignments-1/week-11-recursion) | Power, digit sum, and Fibonacci by recursion | Recursion |
| [week-12-arrays](lab-assignments-1/week-12-arrays) | Input, sum, and merge of one-dimensional arrays | Arrays |
| [week-13-matrices](lab-assignments-1/week-13-matrices) | Input, output, and transpose of matrices | 2D arrays |
| [week-15-pointers](lab-assignments-1/week-15-pointers) | Average, triangle area, and a swap done through pointers | Pointers |

## Lab Assignments 2

Object-oriented programming. Each program is `main.cpp`, except week 11, which has two separate programs.

| Week | Description | Concepts |
| --- | --- | --- |
| [week-02-classes](lab-assignments-2/week-02-classes) | `Student` and `Employee` classes with a small menu | Classes, objects |
| [week-03-constructors](lab-assignments-2/week-03-constructors) | `Person`, `Records`, `Account`, and `Rectangle` | Constructors, member functions |
| [week-04-composition](lab-assignments-2/week-04-composition) | A footballer whose name is a `FullName` object | Composition, destructors |
| [week-05-operator-overloading](lab-assignments-2/week-05-operator-overloading) | `DayTime` increment and decrement, and a `Dollar` conversion | Operator overloading |
| [week-06-operator-overloading](lab-assignments-2/week-06-operator-overloading) | Adding two `Rectangle` objects, and a `Distance` class | Operator overloading |
| [week-09-inheritance](lab-assignments-2/week-09-inheritance) | `Publication` / `Book` / `Tape`, and bank account classes | Inheritance |
| [week-10-inheritance](lab-assignments-2/week-10-inheritance) | `Staff`, `Teacher`, and `Education` | Inheritance |
| [week-11-abstract-classes](lab-assignments-2/week-11-abstract-classes) | Abstract `Shape` with rectangle, triangle, and circle. A second file reads and writes a `Person` record | Abstract classes, file I/O |
| [week-12-file-handling](lab-assignments-2/week-12-file-handling) | Writes number files and reads a contact list and a number list | File streams |
| [week-13-file-records](lab-assignments-2/week-13-file-records) | Contact book stored in the `Person` file: add, read, delete, and search | Classes, binary files |

Week 12 keeps the text files the exercises use (`one.txt`, `two.txt`, `total.txt`, `Contacts.txt`, `Numbers.txt`). Week 13 keeps the sample `Person` data file the program opens.
