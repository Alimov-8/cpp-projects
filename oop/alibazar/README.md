# AliBazar

A console shop program, AliBazar 3.0, written with Rustam Zokirov (U1910049) and Alimov Abdullokh (U1910060) as an EightSoft Academy project.

The original archive held several earlier snapshots of this same program. This folder keeps the latest source, the original requirements note, and the submission screenshots.

## Features

- Loading screen
- Owner sign-in
- Customer registration with checks for name, phone number, and password
- Password entry printed as asterisks
- Three product groups: vegetables and fruit, drinks, and fast food
- Adding and removing items, with a cart total
- Owner menu to view registered customers and edit a product's details, price, and quantity
- Customer records appended to `User_Info.txt`

The owner login checked by this version is `1`, and the password is `1`. Registration rules are also written in `Read Me First.txt`.

## Concepts

- Classes and objects
- Inheritance for products and people
- Input validation
- File input and output
- Console menus

## Files

- `Source.cpp` is the program
- `Products.h`, `Person.h`, `Validation.h`, `Password_Vali.h`, and `Loading.h` are the supporting headers
- `alibazar.sln` opens the project in Visual Studio
- `screenshots/` has the pictures from the course submission

Open `Source.cpp` to read the program. It was built as a Windows console application.
