# C++ Projects

A collection of C++ programs from my freshman year at INHA University, together with console games written around the same time.

The course work covers introductory C++ and object-oriented programming. The games are small Windows console programs. Every project is already extracted, so you can open a folder and read the source directly.

These programs were written in Visual Studio for the Windows console. Many of them use `conio.h`, `windows.h`, and `system("cls")`.

## Games

| Project | Description | Concepts |
| --- | --- | --- |
| [Snake](games/snake) | Console game: move a character, eat fruit, and avoid the walls | Game loop, keyboard input |
| [Guess Number](games/guess-number) | Five rounds of matching a random number, then a luck message | Loops, random numbers, input |
| [Road Game](games/road-game) | Cross a road from start to finish while obstacles move across | Game loop, collision |
| [Dinazavr Rex](games/dinazavr-rex) | A small dinosaur jump game with a score | Game loop, keyboard input |
| [Tic-Tac-Toe](games/tic-tac-toe) | Two-player tic-tac-toe on a numbered board | Menus, game state |
| [New Year Tree](games/new-year-tree) | Animated, colored console holiday tree | Console output, color |
| [Olaf Game](games/olaf-game) | Artwork and audio for an Olaf game. The C++ source was not in the original archive | Assets |

## University labs

Weekly assignments from two lab courses. Each week is one source file (a few weeks also keep the data files the program reads). Several files contain more than one exercise, with earlier exercises left in comments so only one `main` is active.

| Course | Description | Concepts |
| --- | --- | --- |
| [Lab Assignments 1](university/lab-assignments-1) | Introductory C++ exercises, weeks 2–6, 9–13, and 15 | Variables, control flow, functions, arrays, pointers |
| [Lab Assignments 2](university/lab-assignments-2) | Object-oriented exercises, weeks 2–6 and 9–13 | Classes, inheritance, operator overloading, files |

The week-by-week list is in the [university README](university/README.md).
