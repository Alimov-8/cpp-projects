# Tic-Tac-Toe

A two-player console tic-tac-toe game. The board is numbered 1 through 9. Players take turns placing `x` and `o`.

## Features

- Main menu: start, about, and quit
- A cell can be used only once
- Win check and a running score for `x` and `o`
- About page and a quit confirmation

## Concepts

- Menus
- Game state
- Turn-taking
- Conditions
