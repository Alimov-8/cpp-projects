# Road Game

A console road-crossing game. The player (`$`) starts at the bottom and moves toward the finish line while `#` obstacles move across the road.

## Features

- WASD movement
- A start line and a finish line
- Obstacles that wrap across the road
- Hitting an obstacle, leaving the map, or reaching the top row ends the run
- `x` quits

## Concepts

- Game loop
- Keyboard input
- Collision detection
- Console drawing
